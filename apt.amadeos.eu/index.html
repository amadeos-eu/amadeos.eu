amadeOS package repository

The Debian packages of amadeOS: the desktop, its applications and games. Newer amadeOS images have it set up already. On an amadeOS installed from version 1.0.0 it is added once: download amadeos-archive-keyring.deb with Firefox (it lands in Downloads), then in a terminal:

sudo apt install ~/Downloads/amadeos-archive-keyring.deb
sudo apt update

From then on the package amadeos-archive-keyring keeps the key and the source up to date, and amadeOS updates appear in the Front Panel like Debian's. The repository is signed with the key in amadeos-archive-keyring.asc. Browse the packages or the index files.
