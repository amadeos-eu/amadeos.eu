A classic desktop, made new

The amadeOS desktop follows the Common Desktop Environment of the 1990s: a Front Panel with drawers, four named workspaces, Motif window frames and one place for all settings. Its display manager, window manager, panel and settings are new programs in Java.

Under the hood

The desktop consists of a few Debian packages: the display manager with the login screen, the session with screen lock and screen saver, a reparenting X11 window manager, the Front Panel and Settings. The window manager speaks the ICCCM and EWMH standards, so programs that are not written in Java work as well. Part VII of the User's Handbook explains how it all fits together, and What amadeOS adds to Debian gives an overview.
