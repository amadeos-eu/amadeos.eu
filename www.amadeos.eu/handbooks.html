Three handbooks

amadeOS is documented as books, online and installed on every amadeOS computer, where the Help drawer of the Front Panel opens them.

For everyone

User's Handbook

Why amadeOS exists, how to install it, and how to use and administer it, from the first login to the command line. Seven parts and six appendices, with a chapter for every program.

For programmers

Application Developer's Handbook

How the amade applications are written with Java and Swing, one real program per chapter, from the Text Editor to the Mailer, and how to package your own.

For game makers

Game Developer's Handbook

A 2D game engine in Java, built up game by game: from Paddle and Bricks to Sands, Colony and Town, with a complete engine manual.
