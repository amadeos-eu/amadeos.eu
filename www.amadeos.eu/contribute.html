Take part

amadeOS is developed in the open on GitHub. Try it, report what does not work, translate it, or write a program for it.

amadeos

The image: package list, configuration, build scripts, the User's Handbook and the roadmap.

amadeos-system

The desktop: display manager, window manager, Front Panel, Settings and the system tools.

amade-commons

The shared library of the applications and the Application Developer's Handbook.

amade-game-engine

The 2D game engine of the games and the Game Developer's Handbook.

Ways to help

Try it and report

Build the image, start it on your computer and tell us what works and what does not, as an issue in the repository of the program concerned.

Translate

amadeOS speaks English, German, French, Spanish and Italian. Every application keeps its texts in plain properties files, one per language.

Write a program

An amadeOS application is a Java program with a Debian package. The Application Developer's Handbook shows how, step by step.

All contributions are published under the EUPL-1.2. The contributing guide describes how to build and test.
