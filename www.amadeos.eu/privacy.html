2. Server log files

The web server of this website is operated by us. When you open a page, your browser automatically transmits information that the server stores in log files:

  • browser type and version, and the operating system
  • the referrer URL (the page you came from)
  • the IP address of the accessing computer
  • the time of the request and the requested page

We use these log files to operate the website securely, to fend off attacks and to count visits in an aggregated form; for the statistics the country is derived from the IP address on our own server. The data is not merged with other sources and not passed on. The legal basis is Art. 6 (1) (f) GDPR: our legitimate interest in a secure and working website. The log files are deleted after one year at the latest.

3. No cookies, no tracking

This website sets no cookies and uses no analytics service, no social media plugins and no content from other servers. Fonts and scripts are delivered by this server itself.
