Get amadeOS

amadeOS comes as one image file for a USB stick. It starts as a live system that changes nothing on your computer, and installs onto the disk from there, on its own or next to Windows.

amadeOS 1.0.0

Released on 27 October 2026. One image for 64-bit PCs, 1.4 GB.

Check the download

The SHA-256 checksum of amadeos-1.0.0-amd64.iso is

74697532e3712f8975d083d52f163260e24d8168f64af896b92b89ab1345dd20

Download the checksum file next to the image and check it with

sha256sum -c amadeos-1.0.0-amd64.iso.sha256

Chapter 12 of the User's Handbook explains how to write the image to a USB stick and chapter 14 how to install amadeOS. Older and newer versions are on the releases page.

Build it yourself

You can also build the image from the source code with one script:

git clone https://github.com/amadeos-eu/amadeos.git
cd amadeos
./buildDistribution.sh

The script fetches and builds the desktop, the applications and the games and writes artifacts/amadeos-amd64.iso. It needs Debian or Ubuntu with Java 25 and live-build. Chapter 11 of the User's Handbook explains every step.

You can check what is in the image, not only that it arrived intact: the whole source code is public, and anyone can build the same image from it.
