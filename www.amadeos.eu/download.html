Get amadeOS

amadeOS comes as one image file for a USB stick. It starts as a live system that changes nothing on your computer, and installs onto the disk from there, on its own or next to Windows. A Debian or Ubuntu system you already have can get the amadeOS desktop as packages.

amadeOS 1.3.0

Released on 13 November 2026. One image for 64-bit PCs, 1.8 GB. New in 1.3.0: Family Tree for your genealogy (GEDCOM), Label Printer for labels and business cards, the Horizon palettes, a smaller image with Mines and Solitaire on board and the other eighteen games, now with Cruise and Pinball, ready to install from Software, and programs that use less memory and keep working during a Java update.

Alternative: On an existing Debian or Ubuntu

Already running Debian 13 or Ubuntu 26.04 (or Xubuntu, Kubuntu …)? Add the amadeOS desktop from the package repository apt.amadeos.eu, without the image. Your files and programs stay; updates come with the normal system updates. The programs need Java 25: apt policy openjdk-25-jre must show a candidate.

wget https://apt.amadeos.eu/amadeos-archive-keyring.deb
sudo apt install ./amadeos-archive-keyring.deb
sudo apt update
sudo apt install amadeos-desktop

Then let the amadeOS login screen start instead of the old one (here LightDM; gdm3 on Ubuntu, sddm on Kubuntu) and restart:

sudo systemctl disable lightdm
sudo systemctl enable amadeos-dm
sudo reboot

Chapter 17 of the User's Handbook explains every step, how to remove the old desktop and how to go back.

Alternative: Build it yourself

You can also build the image from the source code with one script:

git clone https://github.com/amadeos-eu/amadeos.git
cd amadeos
./buildDistribution.sh

The script fetches and builds the desktop, the applications and the games and writes artifacts/amadeos-<version>-amd64.iso. It needs Debian or Ubuntu with Java 25 and live-build. Chapter 11 of the User's Handbook explains every step.

You can check what is in the image, not only that it arrived intact: the whole source code is public, and anyone can build the same image from it.
