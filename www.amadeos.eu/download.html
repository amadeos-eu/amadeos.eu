Get amadeOS

amadeOS comes as one image file for a USB stick. It starts as a live system that changes nothing on your computer, and installs onto the disk from there, on its own or next to Windows.

Not released yet. The first release will be offered here for download, with its checksum and a list of every package in it. Until then you build the image yourself from the source code with one script.
git clone https://github.com/datazuul/amadeos.git
cd amadeos
./buildDistribution.sh

The script fetches and builds the desktop, the applications and the games and writes artifacts/amadeos-amd64.iso. It needs Debian or Ubuntu with Java 25 and live-build. Chapter 11 of the User's Handbook explains every step, chapter 12 how to write the stick and chapter 14 how to install.

You can check what is in the image, not only that it arrived intact: the whole source code is public, and anyone can build the same image from it.
